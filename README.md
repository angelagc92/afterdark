# AFTERDARK | Digital Book Platform

AFTERDARK is a web project inspired by streaming platforms, designed for discovering, cataloging, and exploring digital books. The project focuses on dark-mode visual aesthetics, intuitive UI/UX interactions, and full-stack integration.

🔗 **Live Demo:** [https://angelagc92.github.io/afterdark/](https://angelagc92.github.io/afterdark/)

---

## 🛠️ Tech Stack & Architecture

* **Front-End**: HTML5, CSS3, JavaScript (ES6+)
* **Styling**: Tailwind CSS (CDN) and custom CSS
* **Typography**: Google Fonts
* **UI Assets**: Custom SVG icons, images, and visual assets
* **Version Control**: Git & GitHub
* **Deployment**: GitHub Pages

---

## ✨ Current Features

- **Responsive Layout:** Adapts the interface to different screen sizes.
- **Horizontal Carousels:** Browse book collections and genres with horizontal scrolling and navigation arrows.
- **Interactive Genre Cards:** Image-based cards with subtle hover effects.
- **Custom Visual Design:** Dark backgrounds, gradients, transparency, and blur effects.
- **Animated Card Hover:** Subtle glow effects and visual feedback when hovering over book cards.
- **Navigation:** Header links connecting the main sections of the page.
- **Login and Registration Pages:** Initial interface layouts for future authentication functionality.
