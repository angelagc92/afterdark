# AFTERDARK | Digital Book Library

AFTERDARK is a web development project focused on creating a digital library for discovering and exploring books. Inspired by dark fantasy aesthetics and literary atmospheres, the platform offers an intuitive browsing experience where readers can explore books, discover new releases, and find their next read.

The project combines a distinctive visual identity with responsive design, accessible navigation, and interactive user interface elements.

🔗 **Live Demo:** [https://angelagc92.github.io/afterdark/](https://angelagc92.github.io/afterdark/)

---

## 🛠️ Tech Stack

- **HTML5:** Semantic structure and accessible web content.
- **CSS3:** Custom styling and visual effects.
- **JavaScript (ES6+):** DOM manipulation and interface interactions.
- **Tailwind CSS:** Utility-first styling through CDN.
- **Google Fonts:** Literata and DM Sans typography.
- **SVG & Image Assets:** Custom icons, illustrations, logos, and backgrounds.
- **Version Control:** Git & GitHub.
- **Deployment:** GitHub Pages.

---

## ✨ Current Features

- **Digital Book Library:** A catalogue-oriented interface designed to discover and explore books.
- **Homepage:** Introduction to Afterdark and a preview of the library.
- **Explore Page:** Dedicated space for browsing the book catalogue.
- **New Releases:** A section focused on recently published books.
- **Responsive Design:** Layouts adapted to desktop, tablet, and mobile screens.
- **Search Interface:** Search field integrated into the main navigation, ready for future functionality.
- **Login & Registration:** Dedicated authentication interface layouts.
- **Interactive Elements:** Password visibility controls, navigation links, and visual hover effects.
- **Custom Visual Identity:** Dark purple palette, gradients, transparency, blur effects, and literary-inspired imagery.
- **Accessibility Improvements:** Semantic HTML, accessible labels, keyboard navigation, visible focus indicators, skip-to-main-content links, and responsive zoom support.

---

## ♿ Accessibility

Accessibility has been considered throughout the interface development process.

The project has undergone an accessibility self-assessment using Google Lighthouse and WAVE, together with manual keyboard and visual checks.

Improvements include:

- Semantic HTML landmarks and heading hierarchy.
- Accessible labels for form fields.
- Alternative text for images.
- Keyboard navigation and visible focus indicators.
- Skip-to-main-content links.
- Improved text contrast.
- Support for browser zoom up to 400%.
- Responsive layouts and scroll behavior.
